A database connection should come from Juno, either supplied to an IDbExecute or created by IAdoConnectionFactory.CreateConnection().

Why is this an issue?

Constructing the connection yourself means supplying the connection string yourself, which is the actual problem: the address, credentials, failover target and pooling settings stop coming from the service's configured data source and start coming from whatever string is in scope at that point. It also bypasses the transaction accessor, so the new connection is invisible to any Juno transaction that is already open - work you believe is transactional silently is not.

public async Task<Order> Find(int id)
{
    using var connection = new SqlConnection(_connectionString);
    return await connection.QuerySingleAsync<Order>("select * from Orders where Id = @id", new { id });
}

Both supported shapes are equivalent as far as this rule is concerned. An IDbExecute lets Juno run the work with the ambient transaction supplied; IAdoConnectionFactory hands back a connection you use directly, typically with Dapper.

The rule reports a constructed DbConnection, a connection obtained from a DbProviderFactory, and a Dapper operation whose connection cannot be traced back to one of the two supported shapes. It targets Dapper Query* and Execute* operations; configuration and utility APIs such as SqlMapper.AddTypeHandler, AddTypeMap, PurgeQueryCache and AsTableValuedParameter do not access a database and are not reported.

How to fix it

Express the work as an IDbExecute, or create the connection through IAdoConnectionFactory.

Code examples

Noncompliant code example

public async Task<Order> Find(int id)
{
    using var connection = new SqlConnection(_connectionString); // Noncompliant
    return await connection.QuerySingleAsync<Order>("select * from Orders where Id = @id", new { id });
}

Compliant solution

public async Task<Order> Find(int id, CancellationToken token)
{
    await using var connection = connectionFactory.CreateConnection();
    return await connection.QuerySingleAsync<Order>(
        new CommandDefinition("select * from Orders where Id = @id", new { id }, cancellationToken: token));
}
