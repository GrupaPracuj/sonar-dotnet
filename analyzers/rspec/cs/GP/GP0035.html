A database connection should be obtained from Juno, not created with new SqlConnection(...) or directly through a DbProviderFactory.

Why is this an issue?

Constructing the connection yourself means supplying the connection string yourself, which is the actual problem: the address, credentials, failover target and pooling settings stop coming from the service's configured data source and start coming from whatever string is in scope at that point. It also bypasses the transaction accessor, so the new connection is invisible to any Juno transaction that is already open - work you believe is transactional silently is not.

public async Task<Order> Find(int id)
{
    using var connection = new SqlConnection(_connectionString);
    return await connection.QuerySingleAsync<Order>("select * from Orders where Id = @id", new { id });
}

Dapper is deliberately not reported. Juno hands you a raw connection on purpose - IAdoConnectionFactory.CreateConnection() returns a DbConnection and IDbExecute.Execute receives an IDbConnection - so querying that connection with Dapper is the sanctioned pattern, not a workaround. What this rule objects to is producing a connection outside Juno, not what you do with a connection Juno gave you.

How to fix it

Take the connection from IAdoConnectionFactory.CreateConnection(), or express the work as an IDbExecute and let Juno pass in the connection and the ambient transaction.

Code examples

Noncompliant code example

public async Task<Order> Find(int id)
{
    using var connection = new SqlConnection(_connectionString); // Noncompliant {{Obtain the connection from Juno (IAdoConnectionFactory / IDbExecute) instead of creating it directly with 'SqlConnection'.}}
    return await connection.QuerySingleAsync<Order>("select * from Orders where Id = @id", new { id });
}

Compliant solution

public class FindOrder : IDbExecute<Order>
{
    private readonly int _id;

    public FindOrder(int id) =>
        _id = id;

    public Task<Order> Execute(IDbConnection dbConnection, IDbTransaction dbTransaction = null) =>
        dbConnection.QuerySingleAsync<Order>("select * from Orders where Id = @id", new { id = _id }, dbTransaction);
}
