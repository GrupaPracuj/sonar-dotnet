Locking that has to hold across processes should go through Juno's ILockableFactory, not a named Mutex or a direct Consul lock.

Why is this an issue?

Juno implements cross-process locking on Consul or SQL Server, which is what makes the lock work between instances of a service spread across machines. A Mutex reaches only as far as one operating system. Microsoft's documentation draws the line:

Mutexes are of two types: local mutexes, which are unnamed, and named system mutexes. A local mutex exists only within your process.
Named system mutexes are visible throughout the operating system, and can be used to synchronize the activities of processes.

"Throughout the operating system" is exactly the limit: a named mutex holds on a developer machine and in a single-node test, then silently stops holding once the service runs as several pods - the classic failure that shows up as duplicated work or a lost update long after the code was written. Going directly at Consul works, but skips the configured lock backend, the acquire timeout handling and the AcquireLockResult contract the rest of the code expects.

using var mutex = new Mutex(false, "Global\\order-import");
mutex.WaitOne();

Exceptions

In-process synchronization is not reported: the lock statement, SemaphoreSlim, Monitor and an unnamed Mutex coordinate threads inside one process, which is a different problem with a legitimate answer. Only a construct whose whole point is to reach beyond the current process is reported.

How to fix it

Create the lock through ILockableFactory and acquire it against a lock resource, so the backend and timeout come from configuration.

Code examples

Noncompliant code example

public void ImportOrders()
{
    using var mutex = new Mutex(false, "Global\\order-import"); // Noncompliant {{Use Juno's ILockableFactory instead of 'Mutex' for locking across processes.}}
    mutex.WaitOne();

    Import();
}

Compliant solution

public async Task ImportOrders()
{
    var lockable = _lockableFactory.Create("order-import");
    var acquired = await lockable.TryAcquire(new SimpleTypeLockResource(typeof(OrderImport)));
    if (!acquired.Success)
    {
        return;
    }

    Import();
}
