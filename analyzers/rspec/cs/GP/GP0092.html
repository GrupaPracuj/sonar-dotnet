Enum.IsDefined should not be used to validate an enum marked with FlagsAttribute.

Why is this an issue?

A flags enum represents bitwise combinations. A combination can be valid even when no enum member has that exact numeric value, while Enum.IsDefined returns true only for named constants. Valid inputs are therefore rejected as undefined.

How to fix it

Validate that the value contains no bits outside the mask of supported flags, or validate individual flags according to the API contract.

Code examples

Noncompliant code example

Enum.IsDefined(typeof(Access), value); // Noncompliant {{Do not use 'Enum.IsDefined' to validate the flags enum 'Access'; combined flag values are valid but may not be named.}}

Compliant solution

(value & ~AllSupportedAccess) == 0;
