Between transaction begin and commit (or TransactionScope.Complete()), keep only the essential SQL work for the same database transaction.

Do not call external network resources (for example REST APIs or message queues) inside a database transaction before commit.

In Juno-based code this includes calls such as RunInTransaction(...) callback bodies that use GP.Juno.EventStream (Publish/Send) or HTTP abstractions like GP.Juno.HttpApiClient.HttpSending.HttpSender and GP.Juno.HttpClient.IHttpClient.

Move network communication after transaction commit/complete or use outbox/integration patterns to preserve consistency.
