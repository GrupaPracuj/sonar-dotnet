A database transaction should not perform external network calls (HTTP requests, message-bus publishes) before it commits.

Why is this an issue?

Making a remote call while a database transaction is still open ties the transaction's outcome to the availability and latency of an external system, and extends how long database locks are held. If the remote call is slow, the transaction stays open longer than necessary; if it fails after the transaction later commits (or the reverse - it succeeds but the transaction then rolls back), the database and the external system end up in an inconsistent state that is hard to reconcile. Keeping a transaction limited to the database work it actually needs, and moving integration calls after commit (or through an outbox), avoids coupling the transaction's fate to systems outside its control.

using (var transaction = await _transactional.StartTransaction())
{
    await transaction.Execute(order);
    await _httpClient.GetAsync("/orders");
    transaction.Commit();
}

Both ways of scoping a transaction are covered. A using block scopes it to the block; a using declaration (using var transaction = ...) scopes it to the rest of the enclosing block, so the statements that follow the declaration are inside the transaction just as they would be inside a block. In either form, calls placed after the Commit() are outside the transaction and are not reported.

How to fix it

Move the network/message-bus call after the transaction has committed, or publish it through an outbox so it only fires once the database change is durable.

Code examples

Noncompliant code example

public async Task Save(object order)
{
    using (var transaction = await _transactional.StartTransaction())
    {
        await transaction.Execute(order);
        await _httpClient.GetAsync("/orders"); // Noncompliant {{Do not call external network resources inside a database transaction before commit.}}
        transaction.Commit();
    }
}

Compliant solution

public async Task Save(object order)
{
    using (var transaction = await _transactional.StartTransaction())
    {
        await transaction.Execute(order);
        transaction.Commit();
    }

    await _eventStream.Publish(order);
}
