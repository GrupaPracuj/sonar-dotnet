The DateTimeKind passed when constructing a DateTime should match what the name of the property, field, variable or method it is assigned to implies.

Why is this an issue?

DateTime.Kind is what later code relies on to convert, compare or serialize a value correctly - for example ToUniversalTime() and ToLocalTime() both behave differently depending on it. When a member is named ExpirationDateUtc but is built with DateTimeKind.Local (or the ambiguous DateTimeKind.Unspecified), the name and the actual value disagree about what the value represents. Consumers trust the name and get a value that silently means something else, which is exactly the kind of mismatch that produces off-by-a-timezone bugs that are easy to miss in review and hard to reproduce in tests.

ExpirationDateUtc = new DateTime(2020, 1, 1, 0, 0, 0, DateTimeKind.Local);

DateTimeKind.Unspecified contradicts either name: it states that the value carries no timezone information at all, while both Utc and Local in a name promise that it does.

Only a member whose name unambiguously says Utc or Local is checked; a name that says neither (for example ExpirationDate) is not flagged, since the correct Kind can't be inferred from the name alone. Only the DateTimeKind passed directly at the construction site (new DateTime(..., DateTimeKind.X) or DateTime.SpecifyKind(x, DateTimeKind.X)) is checked - a Kind corrected further away, in a different method, is not seen.

How to fix it

Pass the DateTimeKind that matches the name, or rename the member to match the DateTimeKind that is actually correct for it.

Code examples

Noncompliant code example

public class Contract
{
    public DateTime ExpirationDateUtc { get; set; }

    public void Init()
    {
        ExpirationDateUtc = new DateTime(2020, 1, 1, 0, 0, 0, DateTimeKind.Local); // Noncompliant {{'ExpirationDateUtc' is named as UTC time, but is constructed with DateTimeKind.Local.}}
    }
}

Compliant solution

public class Contract
{
    public DateTime ExpirationDateUtc { get; set; }

    public void Init()
    {
        ExpirationDateUtc = new DateTime(2020, 1, 1, 0, 0, 0, DateTimeKind.Utc);
    }
}
