Email should be sent through the application's approved email delivery abstraction, not with System.Net.Mail.SmtpClient or System.Web.Mail.SmtpMail.

Why is this an issue?

Reaching for SmtpClient creates a second, undocumented delivery path that commonly hard-codes a relay host and bypasses centralized configuration, observability and delivery policies. Microsoft also advises against the type for new code:

We don't recommend that you use the SmtpClient class for new development because SmtpClient doesn't support many modern protocols.

The API reference summary is equally blunt - "The SmtpClient type is not recommended for new development" - and Microsoft's platform-compatibility note DE0005 records the same deprecation.

using var client = new SmtpClient("smtp.internal");
client.Send(new MailMessage("noreply@gp.pl", user.Email, subject, body));

How to fix it

Send the message through the email abstraction approved for the application. Its implementation can use the organization's delivery service or a maintained SMTP library such as MailKit without exposing SMTP transport details to application code.

The rule reports send calls on directly constructed and injected SMTP clients.

Writing messages to SmtpDeliveryMethod.SpecifiedPickupDirectory is excluded because it stores files locally rather than delivering email over SMTP. The approved relay adapter assembly is also excluded; its name is configurable with allowedAssemblyNames and defaults to GP.Postman.Sender.

Code examples

Noncompliant code example

public void NotifyUser(User user, string subject, string body)
{
    using var client = new SmtpClient("smtp.internal"); // Noncompliant {{Use the approved email delivery abstraction instead of the obsolete 'SmtpClient'.}}
    client.Send(new MailMessage("noreply@gp.pl", user.Email, subject, body));
}

Compliant solution

public Task NotifyUser(User user, string subject, string body, CancellationToken cancellationToken) =>
    _emailSender.SendAsync(new EmailMessage(user.Email, subject, body), cancellationToken);
