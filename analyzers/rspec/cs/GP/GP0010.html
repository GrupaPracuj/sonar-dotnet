A GET endpoint that returns a collection should respond with 200 OK and an empty collection instead of 404 Not Found when there are no items to return.

Why is this an issue?

404 Not Found means the requested resource or route doesn't exist. A collection query that runs successfully but matches zero rows is a different situation: the route and the resource (the collection) both exist, there just happen to be no items in it right now. Returning 404 in that case conflates "this endpoint doesn't exist" with "this list is empty" and misleads clients into treating a normal, valid response as an error.

The rule covers MVC controller actions and inline Minimal API MapGet handlers. For Minimal APIs, it reports Results.NotFound(), TypedResults.NotFound(), and Results.StatusCode(404) only when the same handler also returns a collection through Results.Ok(...) or TypedResults.Ok(...).

When the route visibly identifies a parent resource, for example /customers/{customerId}/orders, a 404 can legitimately mean that the parent customer does not exist. In that case the rule reports only when the 404 branch explicitly checks that the returned collection is empty, such as orders.Count == 0, orders.Length == 0, or !orders.Any(). The checked collection must be the same symbol that the endpoint returns through Ok(...); an emptiness check on a cache or another unrelated collection does not establish that the response collection is empty.

[HttpGet]
public IActionResult GetUsers() =>
    NotFound();

Exceptions

The response factory is resolved semantically: NotFound()/StatusCode(404) must come from Microsoft.AspNetCore.Mvc.ControllerBase/Controller, or from the Minimal API Results/TypedResults. A same-named helper declared elsewhere - including on the controller itself - is not reported.

How to fix it

Return Ok(...) with an empty collection instead of NotFound() when the collection query is valid but matches nothing.

Code examples

Noncompliant code example

[HttpGet]
public IActionResult GetUsers(bool empty)
{
    if (empty)
    {
        return NotFound(); // Noncompliant {{GET endpoints returning collections should return 200 with an empty collection instead of 404.}}
    }

    return Ok(new List<string>());
}

Compliant solution

[HttpGet]
public IActionResult GetUsers(bool empty)
{
    if (empty)
    {
        return Ok(new List<string>());
    }

    return Ok(new List<string>());
}
