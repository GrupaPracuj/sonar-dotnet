Response metadata for HTTP 204, 205 and 304 should not declare a body schema.

Why is this an issue?

These status codes cannot carry a response body. Attaching a concrete response type describes an impossible protocol in OpenAPI and can cause generated clients to expect content that the server must not send.

The rule checks ProducesResponseType, its generic form and equivalent Swagger response metadata on actions and controllers.

How to fix it

Remove the response type while retaining the status declaration.

Code examples

Noncompliant code example

[HttpDelete("{id}")]
[ProducesResponseType(typeof(DeleteResponse), StatusCodes.Status204NoContent)] // Noncompliant
public IActionResult Delete(string id) => NoContent();

Compliant solution

[HttpDelete("{id}")]
[ProducesResponseType(StatusCodes.Status204NoContent)]
public IActionResult Delete(string id) => NoContent();
