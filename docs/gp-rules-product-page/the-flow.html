Developer platform · agenci AI · controlled delivery

Agent nie powinien zgadywać, jak budujemy.

The Flow łączy scaffold aplikacji, instrukcje, wiedzę platformową i analizę statyczną w jedną lokalną pętlę pracy. Agent dostaje kontekst przed zmianą, a konkretny feedback zanim kod trafi do pull requestu.

Problem nie leży tylko w modelu

Więcej kodu bez lokalnego kontekstu oznacza więcej zgadywania.

Model zna C#, ale nie musi znać naszej architektury, wspieranych bibliotek, odpowiedzialności usług ani kontraktów. The Flow dostarcza te informacje w kolejnych momentach pracy, zamiast liczyć na jeden idealny prompt.

01

Ogólny wzorzec zamiast naszego

Agent wybiera popularną bibliotekę lub strukturę, choć platforma udostępnia zatwierdzoną ścieżkę.

02

Brak wiedzy o otoczeniu

Nowy endpoint lub klient powstaje bez sprawdzenia odpowiedzialności usługi, właściciela albo kontraktu OpenAPI.

03

Feedback dopiero na końcu

Problem wykryty w PR lub CI kosztuje więcej, bo trzeba ponownie odtworzyć kontekst zmiany.

Jeden przepływ, wiele źródeł wiedzy

Od scaffolda projektu .NET do zmiany gotowej na pull request.

Każdy element odpowiada na inne ryzyko. Guidance pomaga przed generowaniem, a niezależna analiza następuje zaraz po zmianie.

Konfiguracja MCP

Podłącz źródła kontekstu do agenta.

MCP jest opcjonalnym kanałem lokalnym: daje agentowi dostęp do bieżącego katalogu Plateau i findingów SonarQube. Wymaga tokena oraz uprawnień użytkownika.

Plateau MCP · Claude

claude mcp add --transport http plateau https://plateau-api.pracuj.pl/api/mcp-actions/v1/ --header "Authorization: Bearer ${PLATEAU_MCP_TOKEN}"

Token PLATEAU_MCP_TOKEN jest w Keeperze — nie w repozytorium ani historii shella.

SonarQube MCP · Copilot i Claude

Instrukcje dostawcy: konfigurator oraz README.

Dla naszego serwera ustaw SONARQUBE_URL=https://sonar2.pracuj.pl i user-token SONARQUBE_TOKEN z Keepera.

Connected Mode od scaffolda

pd.tool tworzy .sonarlint/connectedMode.json, który wiąże projekt z https://sonar2.pracuj.pl. To osobne od MCP połączenie dla lokalnej analizy.
